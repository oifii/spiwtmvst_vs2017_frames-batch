# 2. Quick Start: Running the Visualizer

## 2.1 What windows you should see (and what each is for)

When you launch the `spiwtmvst_vs2017_frames-batch` application, it creates a series of Win32 GUI windows according to the global display-flags set at startup. Each window serves a distinct visualization purpose—audio, graphics, images, or Voronoi diagrams. Pointers to these windows are stored in global variables (e.g., `global_pVorogsWindow`, `global_pVorossWindow`) so they can be referenced later in the frame-capture and post-processing routines. The instantiation logic resides in `spiwindowtransparentmidivoroguispectrumtimeframe.cpp`.

### CThirdWindow (Black Window)

- **Class**: `CThirdWindow`
- **Global pointer**: `global_pBlackWindow`
- **Purpose**: Presents a blank opaque black canvas, often used as a background or clear visual layer.
- **Creation**:

```cpp
  if (global_blackwindowdisplay) {
      global_pBlackWindow = DBG_NEW CThirdWindow(...);
      global_pBlackWindow->Create();
      global_pBlackWindow->Show();
  }
```

### CTextWindow (Static Text Window)

- **Class**: `CTextWindow`
- **Global pointer**: `global_pTextWindow`
- **Purpose**: Renders static text (labels, instructions, captions) using a bitmap (`FIBITMAP*`) background.
- **Creation**:

```cpp
  if (global_textwindowdisplay) {
      global_pTextWindow = DBG_NEW CTextWindow(...);
      global_pTextWindow->Create();
      global_pTextWindow->Show();
  }
```

### CSpectrumWindow (8-bit Spectrum)

- **Class**: `CSpectrumWindow`
- **Global pointer**: `global_pSpectrumWindow`
- **Purpose**: Displays a real-time FFT spectrum in indexed 8-bit color using a palette.
- **Creation**:

```cpp
  if (global_spectrumwindowdisplay) {
      global_pSpectrumWindow = DBG_NEW CSpectrumWindow(...);
      global_pSpectrumWindow->Create();
      global_pSpectrumWindow->Show();
  }
```

### CSpectrum24bitWindow (24-bit Spectrum)

- **Class**: `CSpectrum24bitWindow`
- **Global pointer**: `global_pSpectrum24bitWindow`
- **Purpose**: Displays a real-time FFT spectrum in full 24-bit RGB color.
- **Creation**:

```cpp
  if (global_spectrum24bitwindowdisplay) {
      global_pSpectrum24bitWindow = DBG_NEW CSpectrum24bitWindow(...);
      global_pSpectrum24bitWindow->Create();
      global_pSpectrum24bitWindow->Show();
  }
```

### CImageWindow (Seed-Image Slideshow)

- **Class**: `CImageWindow`
- **Global pointer**: `global_pImageWindow`
- **Purpose**: Cycles through a directory of seed images, applying shuffle or tile effects. Exposes parameters (mode, mix ratio, attenuation, grid size) via `CWindowParameter`.
- **Creation**:

```cpp
  if (global_imagewindowdisplay) {
      global_pImageWindow = DBG_NEW CImageWindow(...);
      global_pImageWindow->Create();
      global_pImageWindow->Show();
  }
```

### CTimeframeWindow (Audio Timeframe Visualization)

- **Class**: `CTimeframeWindow`
- **Global pointer**: `global_pTimeframeWindow`
- **Purpose**: Renders combined waterfall, waveform, and autocorrelation displays using OpenGL. Supports batch frame capture to BMP and conversion to MP4.
- **Creation**:

```cpp
  if (global_timeframewindowdisplay) {
      global_pTimeframeWindow = DBG_NEW CTimeframeWindow(
          L"mytimeframewindowtitle", hInstance, myclassname.c_str(),
          "background.jpg", global_imagefilenames,
          global_x, global_y, global_xwidth, global_yheight,
          global_alpha, global_titlebardisplay, 0);
      global_pTimeframeWindow->Create();
      global_pTimeframeWindow->Show();
  }
```

### CVorogsWindow (Voronoi GUI Surface)

- **Class**: `CVorogsWindow`
- **Global pointer**: `global_pVorogsWindow`
- **Purpose**: Displays an interactive Voronoi diagram overlaid with control parameters. Built on top of `spivorogui`.
- **Creation**:

```cpp
  if (1) // with vorogi surface
  {
      CVorogsWindow* pVorogsWindow = DBG_NEW CVorogsWindow(...);
      pVorogsWindow->Create();
      pVorogsWindow->Show();
      global_pVorogsWindow = pVorogsWindow;
  }
```

### CVorossWindow (Voronoi Slideshow)

- **Class**: `CVorossWindow`
- **Global pointer**: `global_pVorossWindow`
- **Purpose**: Automates cycling through Voronoi frames generated per seed image, ideal for batch animation capture.
- **Creation**:

```cpp
  if (1)
  {
      CVorossWindow* pVorossWindow = DBG_NEW CVorossWindow(...);
      pVorossWindow->Create();
      pVorossWindow->Show();
      global_pVorossWindow = pVorossWindow;
  }
```

---

Each of these windows inherits from `CWindowParameter` (or `CVoroguiWindow`) and registers itself in the `_windowparameterpointers` vector passed to Voronoi windows. This allows them to share parameters and synchronize frame-capture behavior across all visible surfaces. The global pointers (`global_pBlackWindow`, `global_pTextWindow`, etc.) are cleaned up at application shutdown to free resources and terminate audio/DSP streams.

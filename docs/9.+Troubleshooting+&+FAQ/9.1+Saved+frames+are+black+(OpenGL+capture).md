## 9. Troubleshooting & FAQ

### 9.1 Saved frames are black (OpenGL capture)

#### Symptom

When running the automated batch-capture of OpenGL windows (via CTimeframeWindow::saveopenglframetobmpfile), all of the resulting BMP files are entirely black, even though the on-screen content is rendered correctly.

#### Root Cause

By default, the code was calling `glReadBuffer(GL_FRONT)` to read pixel data from the front buffer, which on Windows 10 may not contain the fully rendered frame at the time of capture. As a result, `glReadPixels` reads an empty (black) buffer.

#### Resolution

In `CTimeframeWindow::SaveAsBMP`, change the read buffer from `GL_FRONT` to `GL_BACK` so that `glReadPixels` reads from the back buffer where the most recent frame is rendered before swapping. The fix involves:

1. Querying and saving the current read buffer.
2. Setting the read buffer to `GL_BACK`.
3. Calling `glReadPixels` to capture the back buffer.
4. Restoring the original read buffer.

#### Code Reference

```cpp
// in CTimeframeWindow.cpp, inside SaveAsBMP(...)
GLint viewPort[4];
GLenum lastBuffer;

// 1) Get current viewport and compute imageSize...
glGetIntegerv(GL_VIEWPORT, viewPort);
// … allocate data buffer …

// 2) Store current read buffer
glGetIntegerv(GL_READ_BUFFER, (GLint*)&lastBuffer);

// 3) Set to back buffer to avoid black frames on Windows 10
//    (was glReadBuffer(GL_FRONT) before)
glReadBuffer(GL_BACK); // windows 10 fix, frames were saved all black 

// 4) Read pixel data from back buffer
glReadPixels(0, 0, viewPort[2], viewPort[3], GL_BGR, GL_UNSIGNED_BYTE, data);

// 5) Restore original read buffer
glReadBuffer(lastBuffer);
```

#### Verification

1. **Rebuild and run** the application with frame-batch capture enabled (ensure `skipsaveframes` is false or the timer path calls `saveopenglframetobmpfile`).
2. **Inspect the generated BMPs** (e.g., `frames\frame_000001.bmp`) in any image viewer. They should now show the exact OpenGL content.
3. Optionally, **convert the BMP sequence** to JPEG or MP4 using the existing post-processing steps (FreeImage or FFmpeg) and confirm that the video or JPEG sequence is no longer black.

If frames remain black:

- Ensure the OpenGL context is current when `SaveAsBMP` is called.
- Confirm the window is visible (not minimized or off-screen) at capture time.
- Check for any other calls that might override the read buffer between `glReadBuffer(GL_BACK)` and `glReadPixels`.

# 8. Output Files & Folder Layout

## 8.1 Frames Folder (BMP Sequence)

The application writes every captured frame as an individual BMP in a dedicated **frames** folder, then—once post-processing into JPEGs (and video)—automatically deletes those BMPs to conserve disk space.

**Default Location**

By default, the folder used for raw BMP output is specified by the `global_outputfoldername` member, which is initialized to `"frames"` . This path is relative to the process’s working directory.

**Naming Convention**

Each frame is numbered sequentially starting at 1. On each save call:

- `global_frameid` is incremented.
- A filename is constructed as:

```plaintext
  frames\frame_%06d.bmp
```

where `%06d` is the zero-padded frame index (e.g. `frame_000001.bmp`) .

**Saving Frames**

- In **CTimeframeWindow** (`saveopenglframetobmpfile`), after rendering each OpenGL frame, the code does:

```cpp
  string filename = global_outputfoldername;             // "frames"
  filename += "\\frame_";
  sprintf(buf, "%06d", global_frameid);
  filename += buf;                                       // e.g. "frame_000023"
  filename += ".bmp";
  SaveAsBMP(filename.c_str());
```

- **CImageWindow** and **CVoroguiWindow** follow an almost identical pattern in their respective `saveframetobmpfile` implementations, using the same `global_outputfoldername`, `global_framefilenameprefix` (`"frame_"`) and `global_framefilenameext` (`"bmp"`) .

**Post-Processing & Cleanup**

Once the number of captured frames reaches `global_maxnumberofframeperseedimage`, the window class enters its post-processing loop:

1. **Convert to Video** via an FFmpeg `system()` call (omitted here for brevity).

1. **Generate JPEGs**
2. A subfolder under `global_outputvideofoldername` is created for storing JPGs.
3. The code iterates from `i = 1` up to `global_frameid - 1`, loading each BMP, converting it to a 24-bit JPEG, and saving it into the JPG subfolder.

1. **Delete BMPs**

Immediately after each JPG is written, the corresponding BMP is removed:

```cpp
   // After saving JPG:
   DeleteFileA(bmp_filepath.c_str());
```

1. **Reset State**

Finally, the frame counter is reset and `currentlysavingframe` set back to `false` so that frame capture can resume cleanly next seed or session .

This automatic cleanup ensures that only the final JPEG sequence (and optional video) remains on disk, preventing unbounded growth of intermediate BMP files.

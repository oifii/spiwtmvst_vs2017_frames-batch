## 8.2 Video Output Folders and Per-Seed JPG Subfolders

When converting a sequence of captured BMP frames into a video and a parallel JPEG sequence, the application performs three main steps:

1. Create the global video output folder
2. Invoke ffmpeg to assemble the BMPs into an MP4 file
3. Copy each BMP into a per-seed JPEG subfolder

Below is the detailed sequence of operations and naming conventions.

### Video Folder Creation

Before running ffmpeg, the global output-video folder (`global_outputvideofoldername`) is ensured to exist:

```cpp
_mkdir(global_outputvideofoldername.c_str());
```

### Video File Naming Convention

1. **Derive base seed name (no extension):**

```cpp
   string base = global_imagefilenames[global_pVorogsWindow->GetImageID()];
   base  = base.substr(base.find_last_of("/\\") + 1);
   size_t dot = base.find_last_of(".");
   string base_noext = base.substr(0, dot);
```

1. **Append mode-specific tag:**
2. **Image-shuffle mode:**

`_img-shuffle(nx<N>-ny<N>)`, where `N` are the integer values of parameters `"img_nx"` and `"img_ny"`.

- **Voronoi translation animation:**

`_vorotrans-anim`.

1. **Combine for MP4 path:**

```cpp
   string videocutpath =
       global_outputvideofoldername + "\\"
     + base_noext + <tag> + "."
     + global_outputvideofilenameext;
```

### ffmpeg Input Path Resolution

ffmpeg is pointed at the BMP sequence by resolving the absolute frames folder and using the configured prefix/extension:

```cpp
// 1) Clamp FPS and format scale
sprintf(bufferfps, "%d", clamp((int)global_outputvideoframepersecond, 1, 60));
sprintf(bufferscale, "%dx%d", _WIDTH, _HEIGHT);

// 2) Resolve absolute path to frames folder
char absolutepath[_MAX_PATH];
_fullpath(absolutepath, global_outputfoldername.c_str(), _MAX_PATH);

// 3) Build and run ffmpeg command
string cmd = global_ffmpegpath
    + " -r " + bufferfps
    + " -s " + bufferscale
    + " -start_number 1 -i "
    + absolutepath + "\\" + global_framefilenameprefix + "%6d." + global_framefilenameext
    + " -vcodec libx264 -crf 25 -pix_fmt yuv420p "
    + videocutpath;
system(cmd.c_str());
```

### Generating Per-Seed JPEG Sequences

Once the MP4 is produced, each BMP is converted to JPEG in a subfolder named after the seed and tag:

```cpp
// 1) Create per-seed subfolder
string jpgFolder = global_outputvideofoldername + "\\" + base_noext + <tag>;
_mkdir(jpgFolder.c_str());

// 2) Loop over frames
for (int i = 1; i < global_frameid; i++) {
    // Build BMP path
    string bmp = global_outputfoldername
               + "\\frame_" + format("%06d", i) + ".bmp";

    // Load BMP
    FIBITMAP* dib = FreeImage_Load(FIF_BMP, bmp.c_str(), BMP_DEFAULT);
    if (dib) {
        // Convert and save JPEG
        string jpg = jpgFolder + "\\frame_" + format("%06d", i) + ".jpg";
        FIBITMAP* dib24 = FreeImage_ConvertTo24Bits(dib);
        FreeImage_Save(FIF_JPEG, dib24, jpg.c_str(), JPEG_QUALITYGOOD);
        FreeImage_Unload(dib24);
        FreeImage_Unload(dib);

        // Optional: delete original BMP
        DeleteFileA(bmp.c_str());
    }
}

// 3) Reset frame counter
global_frameid = 0;
currentlysavingframe = false;
```

### Voronoi Translation Animation Mode

In `CTimeframeWindow::saveopenglframetobmpfile()`, the same pattern applies with the `_vorotrans-anim` tag and no grid-shuffle suffix:

```cpp
// Video conversion
_mkdir(global_outputvideofoldername.c_str());
string videocutpath =
    global_outputvideofoldername + "\\"
  + base_noext + "_vorotrans-anim." + global_outputvideofilenameext;
// ... invoke ffmpeg as above ...

// JPEG sequence
string jpgFolder = global_outputvideofoldername + "\\" + base_noext;
_mkdir(jpgFolder.c_str());
// ... loop to convert BMP→JPEG ...
```

This layout ensures that for each seed image there is one MP4 video and one matching folder of JPEG frames, organized under the global video output directory.

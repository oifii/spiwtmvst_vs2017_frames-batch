# 1.3 Verifying a first run (resource/menu/About dialog)

After successfully building the `spiwtmvst_vs2017_frames-batch` solution in Visual Studio 2017 and copying any required DLLs (e.g. `portaudio_x64.dll`) into your output folder, you can confirm that the GUI executable is functioning correctly by exercising its menu commands and About dialog.

## 1.3.1 Launching the Application

1. In Visual Studio, select your desired configuration (e.g. Debug | Win32 or Release | x64).
2. Press F5 (Start Debugging) or Ctrl+F5 (Start Without Debugging), or run the built `.exe` directly from the `Debug`/`Release` folder.
3. The main window should appear with the caption you provided when instantiating `CMainWindow`.

## 1.3.2 Verifying the Menu Bar

The menu bar is created via the `IDC_SPIWAVWIN32` resource.  It defines two top-level menus:

```cpp
// spiwindowtransparentmidivoroguispectrumtimeframe.rc
IDC_SPIWAVWIN32 MENUBEGIN
    POPUP "&File"
    BEGIN
        MENUITEM "E&xit",    IDM_EXIT
    END
    POPUP "&Help"
    BEGIN
        MENUITEM "&About .", IDM_ABOUT
    END
END
```

- **File → Exit** sends the `IDM_EXIT` command.
- **Help → About .** sends the `IDM_ABOUT` command.

## 1.3.3 Opening the About Dialog

When you select **Help → About .**, `CMainWindow::wndProc` handles `WM_COMMAND` and invokes:

```cpp
case IDM_ABOUT:
    DialogBox(
        (HINSTANCE)GetWindowLong(hwnd, GWL_HINSTANCE),
        MAKEINTRESOURCE(IDD_ABOUTBOX),
        hwnd,
        About
    );
    break;
```

This displays the modal About dialog defined in the same resource script.

The dialog layout is:

```rc
IDD_ABOUTBOX DIALOGEX 0, 0, 340, 62
    STYLE DS_SETFONT | DS_MODALFRAME | DS_FIXEDSYS 
          | WS_POPUP | WS_CAPTION | WS_SYSMENUCAPTION 
          "About spiwindowtransparentmidivoroguispectrumtimeframetimeframe"
    FONT 8, "MS Shell Dlg"
BEGIN
    ICON "128", IDC_STATIC, 14,14,21,20
    LTEXT "spiwindowtransparentmidivoroguispectrumtimeframe, Version 1.0",
          IDC_STATIC, 42,14,228,8, SS_NOPREFIX
    LTEXT "Copyright (C) 2015-2016 Stephane Poirier",
          IDC_STATIC, 42,26,228,8
    DEFPUSHBUTTON "OK", IDOK, 113,41,50,14, WS_GROUP
END
```

### About-box callback

User input in the About dialog is dispatched to the `About` procedure in **CMainWindow.cpp**:

```cpp
INT_PTR CALLBACK About(HWND hDlg, UINT message, WPARAM wParam, LPARAM lParam)
{
    UNREFERENCED_PARAMETER(lParam);
    switch (message)
    {
    case WM_INITDIALOG:
        return (INT_PTR)TRUE;

    case WM_COMMAND:
        if (LOWORD(wParam) == IDOK || LOWORD(wParam) == IDCANCEL)
        {
            EndDialog(hDlg, LOWORD(wParam));
            return (INT_PTR)TRUE;
        }
        break;
    }
    return (INT_PTR)FALSE;
}
```

When the user clicks **OK** (IDOK) or presses **Esc** (IDCANCEL), `EndDialog` closes the About box.

## 1.3.4 Using Accelerator Keys

An accelerator table lets you open About via the keyboard without navigating the menu:

```rc
IDC_SPIWAVWIN32 ACCELERATORS
BEGIN
    "?", IDM_ABOUT, ASCII, ALT
    "/", IDM_ABOUT, ASCII, ALT
END
```

- Press **Alt + ?** or **Alt + /** to invoke the same `IDM_ABOUT` command.

## 1.3.5 Exiting the Application

- **File → Exit** triggers `IDM_EXIT`, causing `CMainWindow::wndProc` to call `DestroyWindow(hwnd)`, which in turn posts `WM_DESTROY` → `PostQuitMessage(0)` and exits the message loop.
- You can also press **Alt + F4** to close the main window.

At this point, you have verified that:

- The menu bar and its items are correctly loaded from the `.rc` resource.
- The About dialog appears with the expected version string and closes properly.
- Accelerator keys correctly map to the About command.
- The Exit command cleanly terminates the application.

Together, these checks confirm that the build has produced a working GUI executable with its core Win32 resources wired up correctly.

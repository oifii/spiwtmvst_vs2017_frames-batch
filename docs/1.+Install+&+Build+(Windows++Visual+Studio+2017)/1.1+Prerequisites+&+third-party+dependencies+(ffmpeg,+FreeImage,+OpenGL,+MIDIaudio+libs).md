# 1. Install & Build (Windows / Visual Studio 2017)

## 1.1 Prerequisites & Third-Party Dependencies

This section lists the external tools and libraries required to build and run **spiwtmvst_vs2017_frames-batch** on Windows using Visual Studio 2017. You must install or clone each dependency and configure your project’s include and linker settings accordingly.

---

### 1.1.1 FFmpeg

Purpose:

Automated batch conversion of BMP frame sequences into MP4 via command-line calls.

Installation & Configuration

- Download a static Windows build of ffmpeg and place `ffmpeg.exe` in a folder of your choice.
- In **spiutility.h**, set the `FFMPEG_APP_PATH` macro to that full path:

```cpp
  #define FFMPEG_APP_PATH "d:\\spibin\\ffmpeg\\ffmpeg.exe"
```

Usage

- Both **CTimeframeWindow** and **CImageWindow** initialize

```cpp
  global_ffmpegpath = FFMPEG_APP_PATH;
```

and build a command line like:

```plaintext
  ffmpeg.exe -r <fps> -s <width>x<height> -start_number 1 -i <inputPattern> \
    -vcodec libx264 -crf 25 -pix_fmt yuv420p <outputFile>
```

which is then executed via `system()` .

Verification

After a build, run the application with `skipsaveframes` = false; inspect `commands.txt` in the working folder for the exact ffmpeg command issued.

### 1.1.2 FreeImage

Purpose:

Load BMP frames, convert to 24-bit bitmaps, save JPEG sequences for post-processing.

Installation

- Clone FreeImage 3.18.0 for VS2017.
- Place headers under:

```plaintext
  lib-src\freeimage3180_vs2017\dist\x32
  lib-src\freeimage3180_vs2017\Wrapper\FreeImagePlus
```

- Place `FreeImage.lib` in `Dist\x32`; `FreeImagePlus.lib` in `Wrapper\FreeImagePlus\dist\x32`.

Project Configuration

In **Project Properties → C/C++ → General → Additional Include Directories**, add:

```plaintext
..\lib-src\freeimage3180_vs2017\dist\x32;
..\lib-src\freeimage3180_vs2017\Wrapper\FreeImagePlus
```

Link with **Linker → Input → Additional Dependencies**:

```plaintext
..\lib-src\freeimage3180_vs2017\Dist\x32\FreeImage.lib;
..\lib-src\freeimage3180_vs2017\Wrapper\FreeImagePlus\dist\x32\FreeImagePlus.lib
```

Code Usage

```cpp
FIBITMAP* bmp = FreeImage_Load(FIF_BMP, bmpPath.c_str(), BMP_DEFAULT);
FIBITMAP* bmp24 = FreeImage_ConvertTo24Bits(bmp);
FreeImage_Save(FIF_JPEG, bmp24, jpgPath.c_str(), JPEG_QUALITYGOOD);
FreeImage_Unload(bmp24);
FreeImage_Unload(bmp);
```

in **CImageWindow.cpp** .

### 1.1.3 OpenGL

Purpose:

Render timeframe-style visualizations and enable optional OpenGL-based frame capture.

Installation

- Use the Windows SDK’s built-in OpenGL headers:

```cpp
  #include <GL/gl.h>
  #include <GL/glu.h>
```

- No extra include paths required beyond the Windows SDK.

Project Configuration

Link against:

```plaintext
opengl32.lib
glu32.lib
```

under **Linker → Input → Additional Dependencies** .

Code Usage

- **InitGL** sets up a pixel format and creates an OpenGL context.
- **SaveAsBMP** calls `glReadPixels` (with `GL_BGR`) to capture the back buffer .
- Rendering uses `glEnable(GL_BLEND)`, `glBlendFunc`, `glViewport`, `gluPerspective`, `gluLookAt`, etc.

### 1.1.4 PortAudio

Purpose:

Real-time audio input/output with optional ASIO support.

Installation

- Clone PortAudio (2021) and build for VS2017.
- Header directory:

```plaintext
  lib-src\portaudio-2021\portaudio_vs2017\include
```

- DLLs produced under `build\msvc\Win32` (x86) and `build\msvc\x64` (x64).

Project Configuration

Include path under **C/C++ → General**:

```plaintext
..\lib-src\portaudio-2021\portaudio_vs2017\include
```

Link against (Debug Win32 example):

```plaintext
..\lib-src\portaudio-2021\portaudio_vs2017\build\msvc\Win32\Debug\portaudio_x86.lib
```

(Release or x64 variants accordingly) .

Code Usage

```cpp
Pa_Initialize();
Pa_OpenStream(&stream, &inParams, &outParams, SAMPLE_RATE, FRAMES_PER_BUFFER, paNoFlag, AudioCallback, userData);
Pa_StartStream(stream);
// …
Pa_StopStream(stream);
Pa_CloseStream(stream);
Pa_Terminate();
```

in **spiwindowtransparentmidivoroguispectrumtimeframe.cpp** and **spiaudiodevice.cpp** .

To enable ASIO, define `PA_USE_ASIO=1` in **Project → C/C++ → Preprocessor Definitions**.

### 1.1.5 PortMIDI & PortTime

Purpose:

MIDI input/output and high-resolution timing for MIDI events.

Installation

- Clone PortMIDI and PortTime sources.
- Include directories:

```plaintext
  lib-src\portmidi\pm_common
  lib-src\portmidi\porttime
```

- Link against `portmidi.lib` (or `portmidi-dynamic.lib` for x64).

Project Configuration

Under **C/C++ → General → Additional Include Directories** add the above.

Under **Linker → Input → Additional Dependencies**, add:

```plaintext
..\lib-src\portmidi\Debug\portmidi.lib                 // Win32 Debug
..\lib-src\portmidi\x64\Debug\portmidi-dynamic.lib     // x64 Debug
```

Code Usage

```cpp
#include "portmidi.h"
#include "porttime.h"
#include "spimidi.h"
// …
Pm_Open(&pmStream, inputDeviceID, NULL, 512, NULL, NULL, 0);
Pt_Start(1, midiClockCallback, NULL);
// …
Pm_Close(pmStream);
Pt_Stop();
Pm_Terminate();
```

in **spiwindowtransparentmidivoroguispectrumtimeframe.cpp**.

### 1.1.7 VS2017 Include & Linker Settings

In **Solution Explorer**, right-click the `spiwtmvst_vs2017_frames-batch` project and choose **Properties**:

1. **C/C++ → General → Additional Include Directories**

Add paths to all dependency headers:

```plaintext
   ..\lib-src\portaudio-2021\portaudio_vs2017\include;
   ..\lib-src\freeimage3180_vs2017\dist\x32;
   ..\lib-src\freeimage3180_vs2017\Wrapper\FreeImagePlus;
   ..\spiwavsetlib;
   ..\lib-src\tonic\Tonic-master\src;
   ..\lib-src\libsndfile\include;
   ..\lib-src\portmidi\pm_common;
   ..\lib-src\portmidi\porttime;
   ..\lib-src\rfftw_vs2017;
   ..\lib-src\oifii_vs2017u\oifiilib;
   ..\lib-src\oifii_vs2017u\ow_ipl
```

1. **Linker → Input → Additional Dependencies**

Add the corresponding `.lib` names:

```plaintext
   FreeImage.lib;
   FreeImagePlus.lib;
   spiwavsetlib_vs2017.lib;
   portaudio_x86.lib;
   TonicLib.lib;
   Dsound.lib;
   libsndfile-1.lib;
   portmidi.lib;
   rfftw.lib;
   oifiilib.lib;
   ow_ipl.lib;
   ow_iff.lib;
   opengl32.lib;
   glu32.lib;
   winmm.lib;
   msimg32.lib
```

Ensure the correct Debug/Release and Win32/x64 variants match your active configuration.

### 1.1.8 Verifying `FFMPEG_APP_PATH`

After building, open **spiutility.h** to confirm that:

```cpp
#define FFMPEG_APP_PATH "d:\\spibin\\ffmpeg\\ffmpeg.exe"
```

points to a valid `ffmpeg.exe`. If you move `ffmpeg.exe`, update this macro and rebuild . Ensure the path contains no spaces or escape sequences must be doubled.

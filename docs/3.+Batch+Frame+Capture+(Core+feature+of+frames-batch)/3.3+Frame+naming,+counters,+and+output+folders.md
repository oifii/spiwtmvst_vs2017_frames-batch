## 3 Batch Frame Capture

### 3.3 Frame Naming, Counters, and Output Folders

This section describes the global state and naming conventions used by the frames-batch feature to save individual frames as BMP files, manage per-seed frame limits, and organize output into folders. All state is shared across the various window types (image, Voronoi GUI and timeframe windows) via global variables.

#### 3.3.1 Global Frame Capture State

| Variable | Type | Initial Value | Description |
| --- | --- | --- | --- |
| global_outputfoldername | string | `"frames"` | Directory where individual BMP frames are written |
| global_framefilenameprefix | string | `"frame_"` | Filename prefix for saved frames |
| global_framefilenameext | string | `"bmp"` | File extension for saved frames |
| global_frameid | int | `0` | Monotonic counter, incremented each time a frame is saved |
| currentlysavingframe | bool | `false` | Flag set to `true` while a frame is being captured and written |
| skipsaveframes | bool | `true` | When `true`, frame saving is disabled (skipped) |
| global_maxnumberofframeperseedimage | int | `200` (Image),<br/>`10` (Timeframe) | Maximum frames captured per seed image before skipping further saves |


#### 3.3.2 Initialization

Both `CImageWindow` and `CTimeframeWindow` initialize the frame-capture defaults in their `Initialize()` methods.

##### CImageWindow::Initialize

In `CImageWindow::Initialize()`, the capture defaults for image-based windows are set as follows:

```cpp
global_ffmpegpath                 = FFMPEG_APP_PATH;
global_outputvideofoldername      = "d:\\temp-spiwtmvstf-shuffle";
global_outputvideofilenameext     = "mp4";
global_maxnumberofframeperseedimage = 200;
global_outputvideoframepersecond  = 10;
global_framefilenameprefix        = "frame_";
global_framefilenameext           = "bmp";
currentlysavingframe              = false;
skipsaveframes                    = true;
global_outputfoldername           = "frames";
global_frameid                    = 0;
```

##### CTimeframeWindow::Initialize

In `CTimeframeWindow::Initialize()`, the defaults for OpenGL-based timeframe captures are:

```cpp
global_ffmpegpath                 = FFMPEG_APP_PATH;
global_outputvideofoldername      = "d:\\temp-spiwtmvstf-vorotrans-anim";
global_outputvideofilenameext     = "mp4";
global_maxnumberofframeperseedimage = 10;    // for debugging
// global_maxnumberofframeperseedimage = 300; // usual
global_outputvideoframepersecond  = 10;
global_framefilenameprefix        = "frame_";
global_framefilenameext           = "bmp";
currentlysavingframe              = false;
skipsaveframes                    = true;
global_outputfoldername           = "frames";
global_frameid                    = 0;
```

#### 3.3.3 Filename Convention

When a frame is captured, its filename is constructed by concatenating:

1. `global_outputfoldername`
2. a path separator (`"\\"`)
3. `global_framefilenameprefix`
4. a zero-padded six-digit frame counter (`global_frameid`)
5. a dot (`"."`)
6. `global_framefilenameext`

Example code from `CImageWindow::saveframetobmpfile()`:

```cpp
string filename = global_outputfoldername;    // e.g. "frames"
filename += "\\";
filename += global_framefilenameprefix;       // e.g. "frame_"
char buf[256];
sprintf(buf, "%06d", global_frameid);          // e.g. "000123"
filename += buf;
filename += ".";
filename += global_framefilenameext;          // e.g. "bmp"
// => "frames\\frame_000123.bmp"
```

#### 3.3.4 Frame Counter Management

- **Increment:** At the start of each save, `global_frameid` is incremented and compared against the per-seed limit:

```cpp
  global_frameid++;
  if (global_frameid <= global_maxnumberofframeperseedimage) {
      // proceed to capture
  }
```

- **Reset:** After post-processing (video conversion, JPEG export and BMP deletion), `global_frameid` is reset to `0` and `currentlysavingframe` is cleared:

```cpp
  global_frameid = 0;
  currentlysavingframe = false;
```

#### 3.3.5 Skipping and Limiting Frame Capture

- **Skip Flag:** In the display update loop (`SaveAsBMP`), frames are only captured if `skipsaveframes` is `false`:

```cpp
  if (!skipsaveframes) {
      saveframetobmpfile(_hwnd, dc);
  }
```

- **Per-Seed Limit:** The check against `global_maxnumberofframeperseedimage` ensures that after a seed image (or timeframe pass) reaches its frame-limit, further frames are not saved.

These shared globals ensure consistent naming, folder placement, and counter enforcement across all window types in the frames-batch application.
